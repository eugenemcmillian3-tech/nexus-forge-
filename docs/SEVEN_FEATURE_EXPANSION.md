## Security and evidence contracts
All new public backend operations require authentication. Private experiments, packages, policies, audits and media are owner-scoped. Team data is separate and checked against active membership for every operation; private missions and provider credentials are never implicitly shared. Only admins can approve/change memberships; the owner remains an active admin. Viewer writes and revoked access are rejected. Cross-team membership edits are rejected.

Media is stored only from an authenticated server action, not a client-supplied arbitrary storage ID. Files have a 2 MiB upload ceiling and owner registration limits. MIME is declared and allowlisted, not a semantic content assertion. Storage SHA-256 is normalized to hex. Downloads return authenticated bytes without issuing public storage URLs. Failed registrations remove only their newly created temporary blob. Registered files must be included in future backups: use supported Convex snapshot exports with file-storage inclusion, or retain a separately verified private file backup. Table-only exports are insufficient for media recovery.

Protocols freeze their metric, direction, threshold, sample minimum and domains before observations. Case-key replay is idempotent only for identical evidence; conflicts are rejected. Evidence URLs/digests and numeric observations remain operator supplied, not independently verified. Closing requires the minimum total samples and at least one observation in each declared domain. Standard error is descriptive, not a significance or superiority guarantee. No external report is fetched and no agent code is executed by registering a package.
